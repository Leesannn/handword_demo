# 학습 데이터 구성과 기준선 평가

직접 수행한 학습 실험은 8개 임시 클래스의 NumPy kNN 기준선입니다. 앱 담당자가 제공한 r0006 GRU와는 모델·클래스·전처리 버전을 각각 관리합니다.

## 데이터셋 구성

AIHub 기준 124개 시퀀스를 사용했습니다. 클래스는 coffee, milk, sleep_v1~v4, cold, thanks입니다. 촬영 코드 그룹을 기준으로 다음 분할을 고정하고, MediaPipe 재추출 실험에서도 같은 시퀀스·라벨·분할을 유지했습니다.

| 분할 | 촬영 코드 | 시퀀스 수 | 역할 |
|---|---|---:|---|
| train | REAL01~REAL10 | 76 | 이웃 검색 기준 데이터 |
| validation | REAL11~REAL12 | 16 | k 선택 |
| test | REAL13~REAL16 | 32 | 선택 후 고정 평가 |

촬영 코드 그룹의 교집합을 검사했습니다. 이 분할 단위는 데이터의 촬영 코드이며 물리적인 사람 식별자와 구분합니다.

## 학습·평가 절차

1. 전처리 버전과 배열 크기·유한값을 검증합니다.
2. 시퀀스 ID의 고유성, 분할별 클래스 구성, 그룹 중복을 검사합니다.
3. 30프레임 특징을 펼쳐 Euclidean 거리 기반 kNN으로 예측합니다.
4. k=1·3·5를 validation에서 비교하고 정확도 동률이면 작은 k를 선택합니다.
5. 고정 train을 유지한 채 test를 평가합니다.
6. 클래스별 precision·recall·F1과 confusion matrix를 저장합니다.
7. 모델 저장 후 다시 읽은 예측이 기존 결과와 같은지 대조합니다.

동률 투표는 해당 클래스 이웃의 거리 합, 그 다음 클래스 인덱스로 결정해 결과를 재현 가능하게 했습니다. 이웃 투표 비율은 모델의 보정된 정답 확률과 구분합니다.

## 저장된 실험 결과

| 실험 | 프레임 입력 | 선택 k | validation | test | test macro F1 |
|---|---|---:|---:|---:|---:|
| AIHub 2D 기준선 | 50점 XY·검출 특징, 150값 | 1 | 14/16, 87.50% | 30/32, 93.75% | 0.9370 |
| MediaPipe 재추출 기준선 | 59점 XY+마스크, 177값 | 1 | 15/16, 93.75% | 31/32, 96.875% | 0.9683 |

위 값은 2026-11-05 저장 보고서의 동일 소규모 고정 분할 결과입니다. 앱 r0006의 정확도나 실사용 전체의 인식률로 사용하지 않습니다. 결과의 클래스·분할·혼동 행렬을 [학습 근거 JSON](../evidence/model-development.json)에 연결했습니다.

## 손 모양과 위치를 나눈 특징 실험

hand_local_features.py는 세 가지 변환을 구현합니다.

| 변형 | 처리 | 출력 차원 |
|---|---|---|
| original | 기본 XY·마스크 유지 | 177 |
| local_hands_keep_pose | 손 좌표를 손목 상대 좌표로 변환, 몸 좌표 유지 | 177 |
| local_hands_keep_pose_add_wrists | 손 상대 특징에 원래 손목 위치와 유효 마스크 추가 | 183 |

손목이 검출되지 않은 손의 상대 좌표는 마스크로 제외합니다. 후보를 사전에 정하고 train·validation에서 비교한 기록을 남겼습니다. 영상 작업 시제품은 이 특징 변환과 kNN을 연결해 후보 단어·입력 품질·특징 추론 시간을 응답합니다.
