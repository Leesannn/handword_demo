# 팀 개발 과정의 실습 소스

MediaPipe 좌표 처리·kNN 학습·영상 비동기 작업·Kafka·Spark 통계·복구 검사를 수행한 소스입니다. 원본 폴더 구조와 모듈 이름을 보존했습니다. 동일한 모듈이 각 독립 실습 패키지에 포함되는 구조도 유지해 해당 단계의 코드를 읽을 수 있게 했습니다.

| 폴더 | 구현 내용 |
|---|---|
| 03_실습코드 | 녹화, 원시 손 검출, 손 배정, 177값 조립, 정규화, 30프레임, 학습·평가 |
| 02_파이프라인 | 특징·영상 작업 접수, MongoDB 작업·Outbox, Kafka 요청·결과, Spark 원장·통계 |
| kafka_local_v0.1_20261106 | 단일 브로커 KRaft·내부/호스트 리스너·healthcheck |
| team-event-validation | 합성 recognition_result 요청, 1분·5분 통계·원장 반복 처리 검사 도구 |

시제품의 입력·모델·이벤트와 실제 모바일 로그 경로는 [파이프라인 문서](../docs/prototype-pipeline.md)와 [소스 안내](../docs/source-map.md)에 연결했습니다. 코드 파일의 존재는 구현 근거이고, 실행 결과의 근거는 evidence의 보고서별로 표시합니다.
